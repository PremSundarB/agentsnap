# Weekly update: November 5, 2026

**Team:** Bhushan, Arvind, Prem
**Milestone due this week:** Conflict detection (Nov 5). ✅ Done.

## Done since the proposal

- **Snapshots (Oct 25 milestone): done.** APFS clones on macOS and reflinks on
  Linux, with `cp` and portable-copy fallbacks. Methods are probed per filesystem
  (`agentsnap doctor`). Ten workspaces of a 109 MiB repo take 54 ms each and
  22 MiB of disk in total on APFS.
- **Conflict detection (Nov 5 milestone): done.** Write tracking via `stat`
  signatures plus hashes. Read tracking via MCP and a Claude Code hook. Four
  conflict kinds (write-write, stale-write, stale-read, read-write).
  Function-level detail for Python (originally a stretch goal).
- **Merging (Nov 20 milestone): first version done early.** All-or-nothing
  merges under a cross-process lock, with an undo journal for crash safety.
  Policies `human`, `merge3`, `rerun`, `force`. A person approves agent-resolved
  conflicts. `--check` runs the test suite on the merged result before landing it.
- **MCP server (Nov 30 milestone): first version done early.** 11 tools; works
  with MCP SDK 1.x and 2.x; tested over stdio.
- **Quality:** 125 tests, run on macOS/APFS, Linux/overlayfs and Linux/XFS
  with reflink, on Python 3.10, 3.11 and 3.14. CI workflow ready (Linux, macOS,
  XFS-reflink job, build check).
